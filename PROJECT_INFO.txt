================================================================================
 1. PROJECT IDEA & CONCEPT
================================================================================

PROJECT NAME: ChinaFastLane
SLOGAN: "Your Bridge to China's Best Factories"

CONCEPT:
An AI-powered mobile and web application that connects global buyers
(particularly from the Middle East and Arabic-speaking countries) with verified
Chinese manufacturers and factories. The platform serves as a discovery and
sourcing tool, allowing buyers to:

- Search and browse verified Chinese factories by category, location, MOQ, and
certifications
- Use AI-powered chat assistant to find the best factory matches
- Submit Request for Quotation (RFQ) forms directly to factories
- Save favorite factories for later reference
- Receive notifications about RFQ responses and updates
- Manage everything through an admin control panel

TARGET AUDIENCE:
- Global buyers and importers looking for Chinese manufacturers
- Sourcing agents and procurement professionals
- Business owners seeking OEM/ODM partners in China
- Primary language focus: Arabic and English (bilingual)

KEY VALUE PROPOSITIONS:
1. 500+ verified Chinese factories across all major industries
2. AI-powered smart matching to find the right factory quickly
3. Direct RFQ submission with structured quotation requests
4. Full bilingual support (Arabic/English) with RTL layout
5. Mobile-first experience with native app build capability
6. Admin dashboard for monitoring and data management

================================================================================
 2. TECHNOLOGY STACK
================================================================================

FRONTEND:
- React 19 with TypeScript
- Vite (build tool and dev server)
- Tailwind CSS 3.4 for styling
- shadcn/ui component library (50+ components)
- Three.js for 3D globe particle background animation
- React Router v7 for admin panel routing
- Superjson for data serialization

BACKEND:
- Hono (lightweight HTTP framework)
- tRPC 11.x (type-safe API with end-to-end TypeScript)
- Drizzle ORM (type-safe MySQL queries)
- MySQL database (via mysql2 driver)
- jose library for JWT token handling

AUTHENTICATION:
- Kimi OAuth 2.0 integration
- JWT session management
- Role-based access control (user/admin roles)

MOBILE BUILD:
- Capacitor 8.x (native iOS/Android wrapper)
- iOS platform configured (Xcode project)
- Android platform configured (Gradle project)
- Custom app icons and splash screens generated
- All native permissions configured

DEPLOYMENT:
- Full-stack deployment with website_version_manager
- Frontend served from dist/public/
- Backend API served from dist/boot.js
- Database push via Drizzle Kit

 4. DATABASE SCHEMA (10 TABLES)
================================================================================

1. USERS
   - id (serial, PK)
   - unionId (varchar 255, unique) - Kimi OAuth ID
   - name (varchar 255)
   - email (varchar 320)
   - avatar (varchar 500)
   - phone (varchar 50)
   - company (varchar 255)
   - role (enum: 'user', 'admin') - default 'user'
   - country (varchar 100)
   - createdAt (timestamp)
   - updatedAt (timestamp)
   - lastSignInAt (timestamp)

2. FACTORIES
   - id (serial, PK)
   - name (varchar 255)
   - slug (varchar 255, unique)
   - description (text)
   - shortDescription (varchar 500)
   - logo (varchar 500)
   - coverImage (varchar 500)
   - location (varchar 255)
   - province (varchar 100)
   - yearEstablished (int)
   - employeeCount (varchar 50)
   - factorySize (varchar 100)
   - moq (varchar 100)
   - moqValue (int)
   - capacity (varchar 100)
   - leadTime (varchar 100)
   - rating (decimal 3,2)
   - reviewCount (int)
   - isVerified (boolean)
   - featured (boolean)
   - exportMarkets (varchar 500)
   - website (varchar 255)
   - email (varchar 320)
   - phone (varchar 50)
   - whatsapp (varchar 50)
   - wechat (varchar 100)
   - contactPerson (varchar 255)
   - createdAt (timestamp)
   - updatedAt (timestamp)

3. PRODUCTS
   - id (serial, PK)
   - factoryId (bigint unsigned, FK -> factories.id)
   - name (varchar 255)
   - description (text)
   - image (varchar 500)
   - category (varchar 100)
   - priceRange (varchar 100)
   - minOrder (varchar 100)
   - createdAt (timestamp)

4. CATEGORIES
   - id (serial, PK)
   - name (varchar 100)
   - nameAr (varchar 100) - Arabic name
   - slug (varchar 100, unique)
   - icon (varchar 100)
   - image (varchar 500)
   - description (text)
   - factoryCount (int)
   - featured (boolean)
   - createdAt (timestamp)

5. CERTIFICATES
   - id (serial, PK)
   - factoryId (bigint unsigned, FK -> factories.id)
   - name (varchar 255)
   - issuer (varchar 255)
   - certificateNumber (varchar 255)
   - issuedAt (timestamp)
   - expiresAt (timestamp)
   - image (varchar 500)
   - status (enum: 'active', 'expired', 'pending')
   - createdAt (timestamp)

6. FAVORITES
   - id (serial, PK)
   - userId (bigint unsigned, FK -> users.id)
   - factoryId (bigint unsigned, FK -> factories.id)
   - createdAt (timestamp)
   - UNIQUE(userId, factoryId) - prevent duplicates

7. RFQS (Request for Quotations)
   - id (serial, PK)
   - userId (bigint unsigned, FK -> users.id)
   - factoryId (bigint unsigned, FK -> factories.id)
   - productName (varchar 255)
   - quantity (varchar 100)
   - specifications (text)
   - targetPrice (varchar 100)
   - deliveryLocation (varchar 255)
   - status (enum: 'pending', 'sent', 'responded', 'closed')
   - adminResponse (text)
   - adminPrice (varchar 100)
   - createdAt (timestamp)
   - updatedAt (timestamp)

8. CHAT_MESSAGES
   - id (serial, PK)
   - userId (bigint unsigned, FK -> users.id)
   - role (enum: 'user', 'assistant')
   - content (text)
   - metadata (json) - stores AI response data
   - createdAt (timestamp)

9. NOTIFICATIONS
   - id (serial, PK)
   - userId (bigint unsigned, FK -> users.id)
   - type (enum: 'rfq', 'message', 'system', 'recommendation')
   - title (varchar 255)
   - body (text)
   - read (boolean)
   - link (varchar 500)
   - createdAt (timestamp)

10. REVIEWS
    - id (serial, PK)
    - factoryId (bigint unsigned, FK -> factories.id)
    - userId (bigint unsigned, FK -> users.id)
    - rating (int)
    - comment (text)
    - verified (boolean)
    - createdAt (timestamp)

================================================================================
 5. API ENDPOINTS (tRPC ROUTERS)
================================================================================

AUTH ROUTER (auth)
  - auth.me                    Query     Get current user profile
  - auth.logout                Mutation  Clear session/cookie

FACTORY ROUTER (factory)
  - factory.list               Query     List all factories (paginated, filterable)
  - factory.featured           Query     Get featured factories
  - factory.bySlug             Query     Get single factory by slug
  - factory.byId               Query     Get single factory by ID
  - factory.search             Query     Search factories by keyword
  - factory.categories         Query     Get all categories

FAVORITE ROUTER (favorite)
  - favorite.list              Query     Get user's favorited factories
  - favorite.ids               Query     Get user's favorited factory IDs
  - favorite.toggle            Mutation  Toggle favorite on/off

CHAT ROUTER (chat)
  - chat.history               Query     Get user's chat history
  - chat.send                  Mutation  Send message, get AI response

NOTIFICATION ROUTER (notification)
  - notification.list          Query     Get user's notifications
  - notification.unreadCount   Query     Get count of unread notifications
  - notification.markRead      Mutation  Mark single notification as read
  - notification.markAllRead   Mutation  Mark all notifications as read

RFQ ROUTER (rfq)
  - rfq.list                   Query     Get user's RFQs
  - rfq.create                 Mutation  Create new RFQ

ADMIN ROUTER (admin) - Protected by adminQuery middleware
  - admin.stats                Query     Get dashboard statistics
  - admin.factoryList          Query     List all factories (admin view)
  - admin.factoryCreate        Mutation  Create new factory
  - admin.factoryUpdate        Mutation  Update existing factory
  - admin.factoryDelete        Mutation  Delete factory
  - admin.userList             Query     List all users
  - admin.rfqList              Query     List all RFQs
  - admin.rfqRespond           Mutation  Respond to an RFQ

 12. LOCAL SETUP INSTRUCTIONS (WINDOWS 11)
================================================================================

STEP 1: Install Prerequisites
  - Download and install Node.js 20+ from https://nodejs.org
  - Download and install XAMPP from https://www.apachefriends.org
  - Install Git (optional) from https://git-scm.com

STEP 2: Start MySQL Database
  - Open XAMPP Control Panel
  - Click "Start" next to Apache and MySQL
  - Open browser, go to http://localhost/phpmyadmin
  - Click "New" on left sidebar
  - Enter database name: "chinafastlane"
  - Click "Create"

STEP 3: Configure .env File
  - Open the .env file in the project root
  - Set DATABASE_URL=mysql://root:@localhost:3306/chinafastlane
  - If you set MySQL password, use: mysql://root:password@localhost:3306/chinafastlane
  - Set JWT_SECRET to any random string (minimum 32 characters)

STEP 4: Install Dependencies
  - Open Command Prompt or PowerShell
  - Navigate to project folder: cd path\to\project
  - Run: npm install

STEP 5: Setup Database Tables
  - Run: npm run db:push
  - This creates all 10 tables automatically

STEP 6: Seed Sample Data (Optional)
  - Run: npx tsx db/seed.ts
  - This adds 8 sample factories to the database

STEP 7: Start the App
  - Run: npm run dev
  - Open browser: http://localhost:3000

STEP 8: Access the App
  - Mobile app: http://localhost:3000 (iPhone frame)
  - Admin panel: http://localhost:3000/admin

 14. KIMI OAUTH SETUP
================================================================================

To enable login functionality:

1. Go to your Kimi developer portal
2. Create a new application
3. Set callback URL: https://your-domain.com/api/oauth/callback
4. Copy the App ID and Auth URL
5. Add to your .env file:
   VITE_KIMI_AUTH_URL=https://your-auth-url
   VITE_APP_ID=your-app-id

For local testing without OAuth:
- The app works fully without login
- Search, browse factories, AI chat, and admin panel all function
